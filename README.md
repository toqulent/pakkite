# pakkite

A packet monitor proxy for Minecraft: Java Edition. Fork of [pakkit](https://github.com/Hecksmedia/pakkit).

## Download

Latest builds for Windows, macOS and Linux: [releases](https://github.com/toqulent/pakkite/releases/latest).

## Running from source

You need node.js and npm.

- Clone the repo
- `npm install`
- `npm start`
